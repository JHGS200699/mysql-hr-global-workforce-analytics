## 📌 Descripción del Proyecto
Este repositorio constituye un **portafolio analítico integral de 32 consultas SQL de negocio (DQL)** sobre las bases de datos corporativas y demográficas `employees` y `world`. 

El proyecto demuestra dominio en la extracción, filtrado, agregación y cruce de datos relacionales sin paja técnica, orientado a resolver preguntas operacionales y estratégicas.

---

## 🛠️ Cláusulas y Términos SQL Cubiertos
* **Consultas de Selección y Filtrado:** `SELECT`, `WHERE`, `BETWEEN`, `LIKE`, `IN`, `LIMIT`.
* **Funciones de Agregación:** `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`.
* **Agregación Condicional y Lógica:** `GROUP BY`, `HAVING`, `CASE WHEN`.
* **Combinación Relacional:** `INNER JOIN` multi-tabla.
* **Subconsultas de Negocio:** Subconsultas escalares en cláusula `WHERE`.
